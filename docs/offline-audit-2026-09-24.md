# 离线功能复查 · 2026-09-24

本次检查以“本机已有内容，在无网、请求一直不返回、登录状态不可用、关闭重开后仍能使用”为边界。使用虚构数据和临时数据库、EPUB 文件，没有访问或修改用户设备上的阅读数据。

## 确认的问题与修复

| 问题 | 原来的失效路径 | 当前处理 |
| --- | --- | --- |
| 下载副本被临时缓存替代 | 读取章节只取最新 payload，没有选择当前译源的受保护下载；后台还会重新取正文 | 按小说、章节和译源解析实际下载引用；阅读下载时不做联网复核 |
| 离线切换译源仍使用旧来源 | 阅读会话的译源固定在打开时，设置菜单切换没有重选已有副本 | 切换时重新选择对应下载，更新已载入章节；丢弃旧来源的迟到刷新 |
| 网站删章后本地入口丢失 | 新目录覆盖旧目录，阅读启动要求章节仍存在于目录 | 从仍被本地副本引用的正文头部补出“本地保存章节”；续读、书签和下载保留入口 |
| 本地书籍详情等网络 | 已有本地目录仍先请求网站，无网或请求不结束时不能及时打开 | 从本机书架进入已有书籍，直接读取本地目录 |
| 文库续读不持久保存 | 页内比例和 EPUB 章节序号只有内存变量 | 按已下载 EPUB 保存位置文件，离线列表和详情入口共用；坏进度文件不阻止打开正文 |
| 文库隐藏窗口无法完成布局 | 初始化和重排只等待动画帧，隐藏原生窗口可能暂停这些回调 | 字体与图片就绪后，布局等待有定时回退；保留原有真实分页检查 |
| 关闭文库时进度被覆盖 | 原生视图退出时产生的滚动/尺寸变化仍被当成阅读进度 | 已退出的页面停止接收和保存位置事件 |

同时避免书架计算进度时解码所有插图字节，避免图片下载接入后扩大启动时的内存和解析开销。

此前已修的账号过滤与正文插图下载继续纳入回归：本地书架、阅读位置、书签和下载不按网站账号隐藏；已下载图片随正文持久保存，旧下载可补图。

## 2026-09-25 补齐的缺口

- 文库 EPUB 纳入书架“离线”、统一下载管理和容量统计。可以直接打开、移除或补全插图；移除文件保留续读位置。
- 备份格式 v3 携带文库位置，可选包含 EPUB 与已保存的插图，兼容导入 v1/v2。合并只补缺，本机已有文件和位置优先；坏文件在写入前拒绝，数据库合并失败撤回新增文件。
- 浏览过的云端收藏夹、分页列表和阅读历史持久保存在本机。页面先显示已保存列表，网络刷新失败或不返回都不隐藏列表，已保存页仍可翻页；登录失效和退出账号不清除快照。
- 文库下载收集 XHTML/SVG 图片引用、响应式图片和 CSS 图片 URL，并打包进 EPUB。重复引用只请求一次；失败保留正文和已经成功的图片，明确显示待补图数量。旧 EPUB 的索引在本地补建，补图无需账号验证；启动/回到前台会尝试补图，也能手动重试。本地保存、补图提交、移除和导入串行写入，避免移除后被迟到补图复活；损坏文件在有效替换完成前保留，旧读取不能误删新下载。
- 原生验证使用本地 HTTP 图片服务，下载后关闭服务，经备份导入新目录，再从统一管理打开。WebView 确认图片来自内嵌数据且原始宽度为 160，服务总共只收到下载时的一次请求。

## 明确的边界

- 云端离线列表仅包含曾加载并保存的页面和查询；没有下载的正文、从未加载的列表页仍需要联网。新增/移除云端收藏等服务端操作仍需网络。
- 文库外链图片失败会保留“待下载”状态。远程字体、远程样式表或带外部依赖的 SVG 不视为已完整下载的独立图片；已存 EPUB 包内资源保持原有阅读行为。
- 备份仍受 128 MiB 文件/解压大小限制；大批插图超过限制时可只备份记录。未声称完成鸿蒙实机验证或发布。
