# 阅读数据备份

入口：设置 → 备份与恢复。从 1.0.0(19) 开始支持。

默认导出本机网文阅读进度、书签、下载记录、搜索历史和阅读设置，以及这些小说的名称与目录。可选加入已下载的网文原文、译文和插图。不导出登录信息、云端收藏、远程阅读历史、普通阅读缓存或文库 EPUB 及其进度。备份文件使用 `.jfzbackup` 后缀，可在支持此格式的鸿蒙、Android、iOS 和 macOS 版本之间迁移。

导入先预览，再点击“确认合并”。不会整库覆盖。

| 数据 | 合并方式 |
| --- | --- |
| 小说 | 按来源和小说的稳定 ID 匹配，不按书名；本机名称和目录优先，补入缺少的小说、章节 |
| 阅读进度 | 每本书默认选阅读时间较新的位置，时间相同保留本机；允许逐书选择。回读较早章节也可以是较新的有效进度 |
| 冲突位置 | 未选的另一处位置存成书签，已有相同书签时不重复创建 |
| 书签 | 按小说、章节、段落和段内位置去重；导出设备的书签 ID 碰撞不覆盖本机书签 |
| 下载记录 | 按小说、范围和译源合并；新增记录保持暂停，不会自动联网下载 |
| 离线正文 | 按小说、章节和译源补缺；保留本机已有正文，不以导入文件刷新已保存版本 |
| 搜索历史 | 合并去重，本机排序优先，最多保留 8 条 |
| 阅读设置 | 默认保留本机，勾选后才使用备份中的主题、字号等设置 |

重复导入不会重复增加同一位置的书签或同一章节译源的正文。导入不产生远程阅读活动，也不更换当前登录账号。

## 文件与写入保证

格式 v2 是带格式标识、版本、导出时间和正文选项的 gzip JSON，包含已保存的插图；仍可导入不含插图的 v1 文件。不执行文件中的 SQL，不接受任意表、列或文件路径。文件和解压后的数据均限制为 128 MiB，最多 250,000 条记录；超过限制时可改为仅导出记录。

导入先在独立的内存数据库里检查字段、类型、阅读位置、设置和正文引用。预览后若本机记录变化，要求重新预览。最终写入使用一个事务，中途失败全部回滚。系统选择器只授权所选文件；导入临时副本与导出临时文件在操作结束后清理。

## 鸿蒙手动安装版迁移到 AppTest

旧版本没有导出功能，因此首次迁移仍需给旧安装补一次含备份功能的版本，且必须使用与旧安装兼容的签名和 app-identifier。先在旧安装导出文件，保存到应用沙箱外，再检查该文件能够打开并显示正确记录。然后才考虑卸载旧安装、安装 AppTest 版并导入。

2026-09-16 已在 Pura X 上完成同签名覆盖升级：原安装从第 17 版升至第 19 版，原包名、app-identifier 和首次安装时间保持不变，没有卸载。另行安装 `io.github.troyt666.jfzreader.backuptest`（显示为“JFZ 备份测试”），两个安装的数据独立。

实机通过系统文件选择器将备份保存到 Download，并在测试安装中验证：

- 仅记录文件约 118 KB，包含 23 本书、13 条进度、1 个书签和 18 条下载记录；成功恢复。
- 随后导入约 22 MB 的完整备份，只补入 1,796 份章节正文（按章节和译源计数）；重复导入同一文件，所有新增和更新数量均为 0。
- 打开恢复后的章节，阅读位置正确。仅在测试安装中从第 72 段移动到第 73 段，再导入旧记录；默认保留新位置，并将旧位置另存为书签。
- 测试安装重新导出的记录仍包含 23 本书、13 条进度和 18 条下载记录，书签增至 2 个。原安装可以读取并正确预览该文件；取消预览，没有把测试进度合并回原安装。

测试安装没有迁移登录凭据；受账号访问条件限制的书籍仍按原有规则显示。实机截图和日志仅留在忽略目录 `app/build/backup-phone/`，不随源码发布。原应用保持安装；随后按用户要求向 AppTest 提交了第 19 版，当前等待自动预审，发布状态见[内部测试分发](harmonyos-apptest.md)。

## 启动时无法打开章节的修复

2026-09-24 更正：上述历史测试中的本地内容账号过滤已移除。下载、进度和书签属于本机数据，离线、登录失效或切换账号都不应隐藏它们。见[离线功能复查](offline-audit-2026-09-24.md)。

实机测试中同时复现了启动后章节打不开、点击重试仍失败，但返回书架重新进入可以打开的问题。启动时的目录刷新可能暂时不包含正在恢复的小说，原先会因此销毁主页面，让尚未完成的阅读加载继续调用已经失效的页面状态。

现在只在首次创建主页面前显示恢复等待页，后续目录刷新保留主页面。回归测试先复现了页面被销毁的失败，修复后相关 56 项测试通过。Pura X 原安装覆盖升级后，连续三次彻底关闭并重启，均正常恢复同一章节和正文位置。

## 验证入口

- `app/test/reader_backup_test.dart`：格式往返、冲突选择、回读、ID 碰撞、重复导入、不同译源、设置、无效数据、过期预览和事务回滚。
- `app/test/backup_screen_test.dart`：默认选项、取消、错误恢复、冲突选择、窄屏与放大字体。
- `app/test/runtime_wiring_test.dart`：启动恢复阅读期间刷新目录，保留主页面并完成章节加载。
- `app/integration_test/backup_ux_test.dart`：Android 原生界面与虚构数据流程；截图写入 `app/build/ui-ux/backup/`。
- `app/tool/backup_fixture.dart`：只打开内存数据库的原生文件选择器测试窗口；`BACKUP_PICKER_TEST=true` 会依次打开保存和读取窗口，并检查恢复结果。
