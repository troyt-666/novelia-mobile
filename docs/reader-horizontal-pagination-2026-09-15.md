# 网页小说横向分页：缺字与跳页检查

2026-09-15，基线 `83d6bcc`。用户确认问题出现在网页小说，文库 EPUB 未验证。
本轮使用虚构内容检查和修复，未取得用户遇到缺字时的具体段落与排版设置。

## 已确认的问题及修复

- **空原文行漏算高度**：`Text('')` 实际占一行，但分页测量返回零。后续正文因此可能
  被分配到已经放不下的页尾，并由页面的 `ClipRect` 裁掉。新增测试先证明两个正文块
  实际放不下时仍被分到同页；测量现在保留空行的真实高度。
- **单个字符超过页面高度**：旧分片算法为保证前进至少保留一个字符，但渲染分片时
  没有处理它仍高于页面的情况。现在这种分片使用已有的适配缩放路径；可用高度也
  不再被强行抬到 120，避免短视口的计算高度大于实际高度。
- **过期翻页补执行**：在开头向前翻页等待加载期间，再向后翻页，旧请求完成后仍
  执行一次向前翻页。新增回归先复现位置被拉回；现在新的按键、触摸、滚动输入和
  排版切换使旧翻页失效，目录跳转继续使用已有窗口代次校验。
- **窗口扩展打断滑动**：向前拖动接近已加载窗口边缘时，会立即重新分页并主动
  定位。回归复现同一拖动中偏移从 0 跳到 10320。现在等拖动和吸附结束后再应用
  窗口变更；网络响应在手势中返回也延迟应用。重排采用当时页面的起点，在同次布局
  中换算页号，避免先显示新页号对应的错误内容再异步跳回。
- **标题页变成正文页**：标题单独成页时，尺寸变化用持久化的“第一正文块”恢复，
  导致直接跳过标题。新增回归先复现窗口改变后标题消失；尺寸、排版和章节刷新
  现在保留当前页的实际条目，包括标题。

主要修改位于 `app/lib/features/reader/reader_pagination.dart` 与
`app/lib/features/reader/reader_screen.dart`。阅读位置持久化格式未改动。

## 回归和原生证据

- `main_test.dart`、`reader_pagination_test.dart`、
  `reader_horizontal_layout_test.dart`：最终 87 项通过。
- 修改文件静态检查通过。使用 Dart MCP 检查，并用 `dart analyze` 对最终文件复核；
  全项目 `flutter analyze` 包装命令挂起，已停止，没有把它记为通过。
- 全量测试一次运行：360 项通过，1 项失败。失败为此前稳定性记录已注明的
  `generated EPUB behaves correctly in WKWebView`；诊断仍是 `visibility: hidden`、
  `Reader layout did not become ready`。本轮未修改 EPUB 实现或该测试。
  失败日志与截图已保存在忽略目录 `app/build/ui-ux/2026-09-15/wenku-failure/`。
  随后新增的“响应在滑动中返回”回归已包含在上述最终 87 项中。
- 新逐页测试除了拼接核对完整中日文本，也检查每页 `RenderParagraph` 和每行文字
  的实际绘制边界。内容覆盖多个普通段落、空原文行和跨页长段落。

  1.6 倍系统文字缩放两项均通过。虚构小说、浅色阅读背景、1080×2400 像素截图：
  `app/build/ui-ux/2026-09-15/horizontal-page-scale-1.0.png`、
  `app/build/ui-ux/2026-09-15/horizontal-page-scale-1.6.png`。
  最终日志为 `app/build/horizontal-native-evidence.log`；初次截图流程的转换状态在
  测试间被重置，已修正并重跑通过，没有把这一测试工具错误当成应用缺陷。
